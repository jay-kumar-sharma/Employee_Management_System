# Employee Management System

A Microservices-based Employee Management System developed using Java and Spring Boot.

## Tech Stack

- Java 17
- Spring Boot
- Spring Security
- Spring Cloud
- Eureka Server
- API Gateway
- MySQL
- JPA/Hibernate
- Maven
- Git & GitHub

## Features

- Employee Management
- Attendance Management
- Payroll Management
- JWT Authentication
- Role-Based Authorization
- REST APIs
- Microservices Architecture

## Services

- Auth Service
- Employee Service
- Attendance Service
- Payroll Service
- API Gateway
- Eureka Discovery Server

## Run the Project

```bash
mvn spring-boot:run
```
